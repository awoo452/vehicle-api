# Agent instructions

Read `CLAUDE.md` in this directory before writing any code. It is the
instruction file for this app whichever agent you are, and it points at the
Rails Playbook (<https://github.com/awoo452/rails-agent>) for the rules every app here follows.

Before anything else: work on a branch, and never push, open a PR or merge
unless the owner's latest message asks for that specific push.
